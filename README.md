# 🔤 Morse Code Generator

A simple yet powerful command-line tool to convert text to Morse code and vice versa. Perfect for learning Morse code or practicing your encoding/decoding skills!

## 📚 About This Project

This project was created as a learning tool to help understand:
- How Morse code works
- Text encoding and decoding concepts  
- Dictionary/map data structures for character conversion
- Basic input/output handling in programming

Whether you're a student learning Morse code for the first time or a developer looking to understand string manipulation, this tool provides a hands-on way to experiment with Morse code conversions.

## ✨ Features

- **Text → Morse**: Convert any text (letters, numbers, punctuation) to Morse code
- **Morse → Text**: Decode Morse code back to readable text
- **Supports**: 
  - Letters A-Z (case insensitive)
  - Numbers 0-9
  - Basic punctuation (.,?!)
  - Spaces (using `/` separator)
- **Error handling**: Unknown characters are marked with `?`
